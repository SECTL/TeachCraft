# 05 · 构建发布与版本号

## 版本号机制

与分晓同构：

```
正式版：v{Major}.{Minor}.{Patch}          例：v1.0.0
预览版：v{Major}.{Minor}.{Patch}-preview.{RunNumber}   例：v1.0.0-preview.37
```

- **唯一版本源**：仓库根 `Directory.Build.props` 的 `<Version>`。任何脚本不得重复硬编码。
- **触发**：
  - 推送 tag `v1.2.0` → 正式 Release（`prerelease: false`）。
  - push `main` / 手动触发 → 预览版，run_number 来自 GitHub Actions。
- **晋级**：Major = 不兼容；Minor = 新工具/新格式/新平台；Patch = 修复与细节。
- 版本计算脚本：`scripts/version.ps1`（读取 `GITHUB_REF_TYPE`、`GITHUB_REF_NAME`、`GITHUB_RUN_NUMBER`）。
- 预览版会保留在 Releases 中，不再自动转草稿；由维护者按需清理。

## 工作流

`.github/workflows/release-draft.yml`

1. **test**：windows-latest，运行三套 xUnit：分晓 `GradeStrip.Tests`（102 项）、工具箱 `TeachCraft.Tests`（400 项，含竞名报名 / 赛程 / 秩序册端到端与导出设置、工具说明展开、检查更新页与 SECTL 镜像回退、发布身份与版本脚本解析）与织序 `GradeWeave.Tests`（115 项）。任一失败即阻止发布。
2. **build-matrix**：7 RID × 2 部署模式。
3. **publish-release**：汇总资产 → 创建 Release → 生成 SHA256 校验清单（旧预览不再自动转草稿，由维护者按需清理）。

### 矩阵

| RID | 运行器 | 产物 |
| :--- | :--- | :--- |
| win-x86 / win-x64 / win-arm64 | windows-latest | zip + Inno Setup `*-Setup.exe` |
| osx-x64 / osx-arm64 | macos-latest | `.app` → dmg + zip |
| linux-x64 / linux-arm64 | windows-latest（交叉） | zip |

- 不包含 linux-arm：QuestPDF 无该架构原生库。
- Windows/Linux 使用单文件 + `IncludeNativeLibrariesForSelfExtract`；macOS 不启用 native 自解压（Avalonia 官方建议）。
- 发布前删除 PDB（`libSkiaSharp.pdb` 约 84MB、`libHarfBuzzSharp.pdb` 约 21MB），否则包体和签名都会出问题。

### 资产命名

```
TeachCraft-{VERSION_TAG}-{rid}-{sc|fdd}.zip
TeachCraft-{VERSION_TAG}-{rid}-{sc|fdd}-Setup.exe
TeachCraft-{VERSION_TAG}-{rid}-{sc|fdd}.dmg
```

### 安装包

- `installer/TeachCraft.iss`：Inno Setup 6，默认 `PrivilegesRequired=lowest`，装进 `%LOCALAPPDATA%\Programs\TeachCraft`；桌面/开始菜单快捷方式；中文界面。
- `build-installer.ps1`：查找 ISCC；找不到时尝试 `choco install innosetup`；可 `-SkipPublish` 复用 CI 已发布目录。

### macOS

- `bundle/macos/Info.plist`：Bundle ID `cn.teachcraft.app`，可执行文件 `TeachCraft`，图标 `teachcraft.icns`。
- `bundle/macos/build-dmg.sh`：publish → 组装 `.app` → 清理 PDB → ad-hoc 签名 dylib / 主程序 / bundle → `hdiutil` 生成 UDZO DMG + `ditto` zip。
- Info.plist 的两个版本键各用一个独立占位符：`CFBundleShortVersionString` 写含预览段的语义版本，`CFBundleVersion` 写来自 run number 的单调整数串（点分整数，禁用字母）。
- 图标 `src/TeachCraft.App/Assets/teachcraft.icns` 由 PNG 生成（ICNS 容器，含 32–1024 多尺寸）。

## 本地命令

```powershell
dotnet build TeachCraft.slnx -c Release
dotnet test tests/TeachCraft.Tests/TeachCraft.Tests.csproj -c Release
dotnet test tests/GradeWeave.Tests/GradeWeave.Tests.csproj -c Release

dotnet publish src/TeachCraft.App/TeachCraft.App.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -o dist/TeachCraft-win-x64-sc

./build-installer.ps1 -Rid win-x64 -Version v1.0.0 -Deployment self-contained
```
