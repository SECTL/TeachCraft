## 实现要点

- **奖状 UI 审计修复范围（1.40.1，待验证）**：姓名 / 奖项设置分组；定位手柄透明以减少遮挡；预览的未就绪、加载、成功与失败状态分别提示；补充工作表、表头行和列映射指引；提供成品访问入口，输入或设置变化后标记旧结果；处理期间拦截关窗。实现正在进行，以上为本轮范围，实际行为待主执行会话提供构建、测试、交互与视觉证据，见 `07-验证与测试资产.md`。

- **奖状生成**（1.40.0）：底图支持 PNG / JPG / JPEG / WebP / BMP，名单支持 XLSX / XLS。用户必须明确选择工作表、表头行、姓名列与奖项列，不猜列；不需要奖项时明确选择「（不印奖项）」（`AwardColumn = -1`），姓名列与奖项列不能相同。只读取表头行之后的数据，跳过空姓名，去首尾空白并合并连续空白；按原表顺序逐行生成，重复姓名保留。
- **奖状版面与预览**：`CertificateTextPlacement` 将姓名、奖项的中心位置存为底图内的 0 到 1 归一化坐标，字号按底图比例保存。预览与 PDF 共用 `CertificatePageGeometry` 和 `CertificateRenderer.DrawCertificate`，底图等比放入 A4，方向跟随底图；调整位置与字号后两条渲染路径使用同一份布局。姓名与奖项定位点可拖动，方向键微调、Shift 加速，与数值输入双向同步；取消「显示文字定位点」可查看无遮挡成品，定位点不会导出。换图、清除或切换面板取消旧预览，失败可点「重新生成预览」。
- **奖状输出保护**：全部读取、预览、绘制与 PDF 生成都在本机完成；一条有效记录一页。`CertificateRenderer` 在 Core 层拒绝输出覆盖底图或名单，`CertificateBatchToolbox` 拒绝已有同名输出；先写临时 PDF 再移动到目标路径，失败清理临时文件。

- **名单核对**（1.37.0）：支持 TXT/XLSX/XLS，文本按行读取，工作簿自动寻找「姓名」列；忽略空行，去首尾空白并将内部连续空白合成一个空格，以 Ordinal 精确匹配。UTF-8 报告列出应交/已交非空行数（含重复）、未交姓名、已交重复姓名及次数、名单外姓名；应交重名单列为错误，不静默去重。复用多文件列表与单文件输出管线，恰好两份才可运行，Core 拒绝报告覆盖任一输入。
- **Excel按班拆表**（1.38.0）：读取 XLSX/XLS，前 20 行查找「班级 / 班别 / 行政班 / Class」表头，按非空班级值计分；多个同分候选或找不到班级列时拒绝静默拆分。唯一候选时先显示工作表、班级列和班级数，再在输出文件夹按班生成重新排版的 XLSX；原工作簿不修改，已有同名输出拒绝覆盖。首版不承诺保留宏、外部链接与原始工作簿全部样式。
- **试卷排版**（1.39.0）：PDF 单页按 2 合 1 或小册子顺序重新排列；可选 300 / 600 / 1200 DPI 最终印刷清晰度，默认 600，按半页版位折算每页渲染像素并启用 PDFium 分块渲染。逐个版面生成临时 PDF 再合并，解码位图工作集限制在当前版面（最多两页）；1200 DPI 的 A5 源页仍可能需约 266 MiB 单页位图。小册子补足 4 页倍数，输入输出不能相同。首版输出为图像化 PDF，不保留原 PDF 的可编辑矢量结构。

- **图片解码**：`SKCodec` + 强制 BGRA；按 EXIF `EncodedOrigin` 摆正手机照片。
- **JPG 输出**：先铺白底再绘制，避免透明背景变黑。
- **水印**：按图像平均亮度自动选白字或墨字；始终加一层反色阴影保证可读。
- **压缩**：PNG 无损，画质滑块不改变 PNG 质量，体积收益主要靠缩小边长；界面结果文案会明确说明。
- **PDF 合并/拆分**：PDFsharp 导入页对象，禁止输出路径覆盖任一输入。
- **PDF 转图片**：PDFtoImage（PDFium）渲染，逐页写 PNG，`Progress<int>` 汇报。
- **PDF 转 Word 文字模式**：PdfPig `ContentOrderTextExtractor` 提取，OpenXML 逐行建段；分页保留。
- **PDF 转 Word 版面模式**：每页按 DPI 渲染成 PNG，按 A4 内容区缩放后嵌入 DOCX；视觉保真但不可编辑。
- **Word 转 PDF**：OpenXML 读取段落/表格 → QuestPDF A4 排版；标题、加粗、斜体、下划线、居右/居中、表格边框保留；页脚页码。
- **图片合成 PDF**：QuestPDF 每页一张图，A4 根据横竖自动切换，`FitArea` 居中。

## 分晓入口

- 「案头常备」卡片与侧栏「分晓 · 成绩条」都打开右侧详情抽屉。
- 详情内展示两张真实截图、平台/输入/输出/数据说明、三条功能摘要。
- 「打开应用」→ 同进程创建分晓主窗口；不是启动外部 exe。
- 分晓有两条导入通道：
  - 「选择成绩总表」只接受能生成成绩条的学生成绩数据（全科汇总、单科成绩报告、学生小题明细）；
  - 「导入分析报表…」接受智学网导出的统计对比、学业等级/分段、临界生、优秀生学困生、缺考、需关注、试卷分析等文件，解析后显示在数据概览底部的「分析报表」区块（报表 chip + 工作表切换 + 只读表格）。
- 分析报表不需要先导入成绩总表：没有任何考试会话时报表存在独立区，概览页只显示「分析报表」区块，拖入即看；之后导入成绩总表会自动并进新会话。走错入口（用「选择成绩表」选到报表）也会自动按报表导入，不再拒绝；客观题填涂表（准考证号/姓名/科目/客观分/题号列）由导入器在结构层拒绝，题号列不会被当成科目读出假成绩会话。zip 会提示先解压。
- 导入 / 解析 / 导出期间盖一层忙碌遮罩：`#66141413` 暗幕 + 纸色卡片（0.22s 放大淡入）+ 陶土弧线匀速旋转（0.9s / linear），主文案跟随 `BusyText`，多文件拖入时显示 `2/3`；不忙时动画类被摘掉，不空转 CPU。样式 `Border.busy-in` / `Canvas.busy-spin` 同步在 `src/TeachCraft.App/App.axaml`。
- 拖拽与启动参数自动分流：成绩表建立/新增考试会话，分析报表挂到当前会话；混拖时先处理成绩表；只拖报表且无会话时提示先拖成绩总表。
- 混合工作簿（一个文件既有成绩数据又有报表页）两条通道同时产出：导入成绩后自动挂载文件内报表，状态栏提示「含 N 份分析报表」。
- 多班级报表在标题右侧提供班级下拉：单班成绩表导入全年级报表时自动默认定位到该班（「九A1」≈「九年级A1」），否则「全年级」；行式报表裁行、列式报表保留公共列与所选班级列；无班级维度时隐藏。

## 归位 · SeatGrid（常备应用）

- 详细实现与边界见 `.memory/09-归位座位表.md`。

## 时序 · ClassBlock（常备应用）

- 导出：打印 PDF（A4，位图嵌入）、PNG 图片；界面中显示的即为同一张图。

## 织序 · GradeWeave（常备应用）

- 侧栏「织序 · 课表编排」与案头常备卡均可打开，同进程独立窗口，单实例复用。
- 定位：时序的上游。时序把已有总表排版打印，织序先把全年级总表排出来。
- 五步流程：01 确认作息时间表 → 02 教研 → 03 分层走班 → 04 领导会议 → 05 正式编排；作息未确认时生成按钮禁用。
- 自动保存：每 2 秒检查工程改动，当前 `.weave.json` 原子写回；无路径或写入失败时保存到本机恢复文件，底部状态栏显示保存时间，空状态可恢复上次自动保存。
- 作息：一天的正课 / 早读 / 课间 / 午餐 / 课服 / 晚修等时段可编辑；内置七 / 八 / 九年级预设，确认后编译为节次，改动即失效。
- 导入：年级工作簿 `.xlsx`（分工表 / 确认表 / 课程表 / 会议活动备注），自动提取班级、学科、教师、任课关系与周课时；`.xls` 提示另存为。
- 约束：教研按学科锁定，会议按岗位 / 指定教师锁定（可放课后服务 / 晚修扩展时段），分层走班按 A/B 层同步占用；走班组教师下拉只列当前学科任课教师，选中教师自动带入其任课班教室；先定约束再排普通课。
- 编排：每班教学时段视为排列，分散式初始分配 + 最小冲突局部搜索；超时降级并列出未排课程，不谎报排完。同一班级同一学科每天 ≤ 2 节、下午 ≤ 1 节，主课优先上午。20 班 / 62 教师 / 694 节的真实规模回归可排满。
- 冲突：教师冲突、班级冲突、教师不可用（教研 / 会议）、走班冲突、缺任课教师、课时不符、未排课程，共七类，均带星期与节次。
- 导出：总表、分工表、班级课表、教师课表、冲突页的 Excel；PNG；班级 / 教师打印 PDF。
- 首版边界：单年级、五天；正课节次由已确认作息决定（默认 7 节）；课服 / 晚修只作为扩展时段，不参与正课自动编排；暂不导入 B 层学生名单。
- 详细实现与边界见 `.memory/12-织序课表编排.md`。

## 作业整理 · Homework（常备应用）

- 侧栏「作业整理」与案头常备卡均可打开，同进程独立窗口，单实例复用。
- 批次：内存内多批次，新建 / 打开 / 返回；关窗前若有未提交且含页的批次先确认。
- 导入：图片 JPG / PNG（按文件名自然排序、EXIF 摆正、缩略图）与多页 PDF（逐页拆开）；同一来源同一页不得重复加入；取消按文件原子回滚。
- 名单：`.xlsx` / `.xls` / `.csv` 或手动粘贴；工作表、表头行、姓名 / 学号 / 班级列明确选择，可混多个班；同班重复非空学号拒绝，重名只警告。
- 匹配：三栏（待处理 / 预览 + 缩放 + 缩略图 / 学生匹配），点学生即匹配并跳到下一张；左栏设「每人应交页数」，交齐的学生移入「已匹配」页签，可在下方逐页或整人撤回；支持撤销重做、删除页、上下移动、班级筛选、搜索、字母索引。
- 导出：改名归档、每人合并 PDF、归档加索引、仅分文件夹四种；纯预检先算冲突与缺页，执行时保护导入来源、取消只删本次创建的文件。
- 填涂识别（1.42.0）：可生成智学网式 A4 学号填涂模板（PNG / PDF，300 DPI 2480×3508，列数 1–12、行 0–9、左侧补 0、数字格实线边框）；在预览上框选数字格区域（批次级 + 单页覆盖），一键识别后按学号唯一匹配，只把读不出或跨班重复的页留在待处理并写明原因。检测阈值与匹配规则固定，一次运行一步撤销，取消不写入，名单重导清理识别结果；全程本机完成，无 OCR / 二维码 / 仅 Windows 代码。详细契约见 `.memory/13-作业整理.md`。
- 扫描任务（1.43.0）：Windows 直接扫描（WIA）+ 全平台收件文件夹，两条路都自动导入当前批次或新建批次；界面为原创 `ScanTaskWindow`，不是 Windows 传真和扫描的复刻。
- 扫描驱动能力（1.44.0）：扫描选项按 WIA 驱动报告的来源 / 尺寸 / 分辨率 / 色彩显示；未报告时用保守默认值并提示；8K/16K 不在 A 中显示。C（TWAIN）待决策见 `.memory/14-扫描驱动能力与TWAIN待决策.md`。

## 首次引导（工具箱）

- 首次启动时，主窗口内覆盖一层四页引导：欢迎 / 本机优先 / 盒子里有什么 / 先从这三件开始。一屏一页、不滚动，1120×720 下也放得下（内容约 394px，卡片可用约 397px）。
- 可随时「跳过」，跳过与看完一样被记住；侧栏底部「检查更新」下方有「首次引导」入口，可随时从第一页重看。
- 状态落在 `%LOCALAPPDATA%\TeachCraft\Oobe\state.json`，原子写；文件损坏 / 不可写一律当未完成，且不会因为存不下来就每次启动都弹。
- **只在第一次打开软件时显示**：结束过引导（看完或跳过）就再也不自动弹，与版本号无关。想重看有侧栏底部的「首次引导」入口。
- 第 3 页的条目全部从 `ToolDescriptionCatalog` 取（`Name` + `Tagline`），目录加一件工具，引导自动跟上；`OobeContentTests.CatalogNamesMatchMainViewModel` 把目录与主界面的名称钉死。
- 第 4 页给三条可点击入口（打开分晓 / 打开归位 / 打开检查更新页）。它们调用的就是侧栏同一个打开动作——不选工具、不读文件、不载示例数据；「打开检查更新页」只开面板，不触发检查。
- 键盘全程可用：Enter / 空格下一步、←→ 前后翻、Esc 跳过（并记录）。系统开启减弱动效时不做翻页位移。
- 引导打开时，主内容区被 `IsEnabled=false` 整条禁用（Avalonia 没有焦点陷阱），遮罩根不透明，被置灰的侧栏不会透出来。

## 检查更新（工具箱）

- 入口在侧栏底部，位于 LOCAL ONLY 联网说明与版本号之间（`nav nav-action` + 刷新图标），不在状态栏；状态栏右侧显示当前版本与 `14 TOOLS · 5 APPS`。有新版时状态栏中间另有「更新 / 稍后」提示条。
- 点入口打开独立的「检查更新」页 `src/TeachCraft.App/Views/UpdatePanelView.axaml`，与工具面板、项目面板共用同一个抽屉（宽 452），三者由 `MainViewModel.IsPanelOpen` 互斥。
- 页面分三节：**当前安装**（构建形态与身份、上次检查时间）/ **检查结果**（结果文字、下载进度、更新 / 跳过按钮）/ **联网与隐私**（说明只有点页内「检查更新」才联网，不发送本机信息，记录只留在本机）。
- 打开页面本身**不联网**；真正的请求由页内「检查更新」触发。`UpdateWiringTests` 守卫这条（`OpenUpdatePanel_DoesNotGoOnline`），并守卫面板互斥、关闭、身份描述与提示文案刷新。
- 来源：默认 GitHub Releases，连不上自动回退 SECTL 镜像；用户可在页内手动选源，选择持久化在本机 `state.json`，手动选源时不回退。实际使用的源与所选不一致时界面必须明示（`HasSourceNote`）。镜像的版本登记 / 包同步细节见 `05` 与 `06`。
- 走查：`--panel update` 打开这一页截图。

## 面板状态机

1. 未选文件：投放区 + 选项 + 禁用「开始处理」。
2. 已选文件：显示文件名 / 多文件有序列表；「清空」可用。
3. 处理中：禁用按钮，显示进度条与百分比（长任务）。
4. 成功：结果摘要 +「打开所在文件夹 →」。
5. 失败：结果文字变陶土色，状态栏圆点同步变红；按钮恢复可用，方便重试。

## 交互补充

- 拖拽：抽屉打开时，整个窗口接受文件投放；单文件工具取第一个，多文件工具追加并去重。
- 搜索：按名称、ID、描述、输入/输出格式匹配；无结果时隐藏空分类并显示空状态。
- **工具说明展开**（1.16.0 起）：当前 14 件工具与 6 件常备卡默认只显示短描述，点卡片或卡片标题才展开完整说明（一句话定位 + 功能要点 chip + 输入 / 输出 / 处理方式 + 三条功能摘要），再点一次或点「收起说明」收回。卡右上「打开」进抽屉，与展开互不影响。说明文案在 `ToolDescriptionCatalog` 单点维护，并且同样进入搜索命中面。
- 多文件顺序：每行 `↑ ↓ ×`，序号实时重排。
- 键盘：`Ctrl/Cmd + K` 聚焦搜索，`Esc` 关闭抽屉或清空搜索。
- 无障碍：工具卡、侧栏导航、投放区、开始处理按钮均设置了 `AutomationProperties.Name`。

## 已知边界

- Word 转 PDF 不渲染 DOCX 内嵌图片、页眉页脚、分栏、浮动对象。
- PDF 转 Word 文字模式会丢失复杂版面；需要版式时选「保留版面」。
- PDF 转图片输出到文件夹，不自动打 zip（桌面场景更自然）。
- 加密 PDF 会提示先解除密码，不做破解。
- `linux-arm` 不支持（QuestPDF 原生库缺失）。
