# 13 · 作业整理（Homework）

第六件常备应用，暂名「作业整理」，程序集 `Homework.App` / `Homework.Core`，目录 key `homework`。目标：把扫描的作业页按学生归档，识别不出的进入异常处理人工匹配。

## 形态与边界

- 由工具箱同进程打开（`HomeworkWindow`），单实例复用；`Homework.App` 保持 `Library`。
- 第一阶段（1.41.0）只做手动匹配；第二阶段（1.42.0）新增填涂识别；第三阶段（1.43.0）新增扫描任务（Windows WIA 直接扫描 + 全平台收件文件夹）。二维码 / 条码、印刷学号 OCR、手写姓名 OCR 仍不做。
- 批次只存在于进程内，不落工程文件；关窗前确认，避免误丢。
- 本地优先：不联网、不上传；原始文件只读，导出绝不覆盖导入来源。

## 数据模型（`Homework.Core.Models`）

- `HomeworkBatch`：`Classes` / `Students` / `Pages` / `State`（Editing / Committed / Abandoned）。
- `HomeworkClass(Id, Name)`、`HomeworkStudent(Id, ClassId, Number, Name)`（学号可空）。
- `HomeworkPage`：`Id`、`SourcePath`、`Kind`（Image / PdfPage）、`SourcePageNumber`（1 基）、`Index`（0 基密集）、`StudentId?`、`UnknownLabel`、`ContentHash`、像素尺寸、`IsDuplicateHint`。
- `BatchEditSnapshot`：页顺序 + 每页匹配；值相等（顺序逐项、字典无序）。

### 不变量

1. `Index` 始终密集（0..N-1），删除 / 移动后压紧。
2. `UnknownLabel` 单调分配（`未知1`、`未知2`…），删除后不重编号、不复用。
3. 同一 `(完整路径忽略大小写, 页码)` 不得同时存在两页；删除后再导入同一来源会复用原页（不产生重复）。
4. 已删除的页仍留在批次内，因此删除可撤销；`Restore` 对未知页 / 未知学生抛 `HomeworkException`。
5. 只有 `Editing` 可改动；提交要求「至少一页且全部已匹配」；提交 / 放弃后只读。
6. 同班重复非空学号 → 拒绝导入；同班同名 → 警告 + 行上「重名」标记。
7. 内容哈希相同只打「重复」提示，不阻断导入。

## 名单导入（`Homework.Core.Roster`）

- `HomeworkRosterImporter`：`.xlsx` / `.xls` / `.csv`（ExcelDataReader，回退 GBK 936）；工作表 / 表头行 / 姓名列 / 学号列 / 班级列由用户明确指定，`GuessColumns` 只给默认建议。
- 班级列缺省时全部落到默认班级；可混多个班。
- 数字型学号按文本保留（`1` 不得变成 `1.0`）；空姓名行跳过并计数。
- `RosterPasteParser`：每行一名学生，支持 `姓名`、`学号 姓名`、`学号,姓名`、`班级,学号,姓名`、Excel 制表符；逐行报错（含行号），重复学号跳过。

## 页面导入（`Homework.Core.Pages`）

- 图片：`SKCodec` 缩放解码（不整张解 50MP 照片）、EXIF 摆正、64×64 灰度 SHA-256 内容哈希、缩略图缓存。
- 图片按文件名自然排序（`IMG_2` 在 `IMG_10` 前），不依赖选择器顺序。
- PDF：PdfSharp 读页数，PDFtoImage 渲染预览（长边 ≤1600、DPI ≤150）；逐页加入。
- 单文件原子：取消或渲染失败时回滚该文件已加入的页；图片之间取消保留已完成文件。
- 缩略图落在 `%TEMP%\TeachCraft\Homework\cache\{会话}`，窗口关闭删除，另清理一天前的残留。

## 匹配界面（参考图）

- 三栏：左侧待处理列表（待处理 / 全部）、中间页面预览（缩放 `- / 百分比 / + / 适应` + 底部缩略图条）、右侧学生匹配（班级下拉、未匹配 / 已匹配 / 全部、搜索、字母索引、行上「未匹配 / 缺 N 页 / 已完成」、底部「删除该张」）。
- 左栏「每人应交页数」（1–99，默认 1）只决定判断与筛选，不改动已匹配的页：`HomeworkBatch.ExpectedPagesPerStudent` / `SetExpectedPages`。页数不足的学生留在未匹配页签并显示「缺 N 页」；交齐后离开未匹配页签、进入「已匹配」，行上「已完成」。
- 「已匹配」页签里的学生只选中、不再匹配新页；下方列出该生已匹配的每一页，可逐页「撤回」或「撤回全部」。撤回走 `HomeworkBatch.UnmatchPage` / `UnmatchStudent`，与匹配共用同一撤销栈，`Ctrl+Z` 可恢复。
- 点学生即匹配并自动跳到下一张待处理页（已交齐的学生只选中，不重复匹配）；`Ctrl+Z` / `Ctrl+Y` 撤销重做；`Delete` 删除当前页、`PageUp/PageDown` 在可见页之间切换。
- 页序按 `Index`；页码在导出时按学生在批次内的先后重排为「第N页」。
- 提交前若有未匹配页，明确拦截并提示数量；未交齐学生按人数与总缺页数在确认框里报数，只警告不阻断，导出预览与完成摘要如实列出。

## 导出（`Homework.Core.Export`）

四种输出，统一走「纯规划器 → 执行器」：

1. `RenameArchive`：`根/班级/班级_学号_姓名_第N页.<原扩展名|pdf>`。
2. `MergePdf`：每位有页学生一份 `根/班级/班级_学号_姓名.pdf`，按 `Index` 合并。
3. `ArchiveWithIndex`：同 1，另出 `作业索引_{批次名}_{yyyyMMdd-HHmmss}.xlsx`（汇总 / 明细 / 未匹配三页）。
4. `CopyToFolders`：`根/班级/班级_学号_姓名/原文件名`，同名加 ` (2)`。

- 规划器 `HomeworkExportPlanner.Build(batch, options, IFileProbe, now?)` 不写盘，产出条目、冲突、缺页学生与警告。
- 冲突：目标已存在且未允许覆盖；目标等于任何导入来源（永远禁止）；条目之间目标路径相撞。
- 文件名清洗：非法字符、Windows 保留名、尾部点 / 空格、120 字上限；班级文件夹重名加 `(2)`。
- 执行器 `HomeworkExporter.Execute` 逐条写；图片按字节复制，PDF 页抽出为单页 PDF；取消时只删本次创建的文件；进度 0–100。

## 第二阶段：填涂识别（1.42.0）

只做确定性的填涂识别，不引入 OCR、二维码 / 条码，也没有任何仅 Windows 的代码、包、TFM 或 UI 分支。模板 PDF 复用解决方案已有的 QuestPDF（与桌贴 / 座位表 / 课表同一条「高分辨率 PNG 嵌入 A4」管线），没有新增解决方案之外的依赖。全部识别在本机完成，不联网、不上传。

### 智学网式填涂模板（`FillInTemplateRenderer`）

- `RenderPng(FillInTemplateOptions)` / `RenderPdf(FillInTemplateOptions)` 返回 `byte[]`，PNG 由 SkiaSharp 直接绘制，PDF 把同一张 PNG 铺进 A4，两种格式版面逐像素一致。
- 版面以 300 DPI 的 A4 纵向为基准，即 2480×3508 像素；其余 DPI 按比例缩放。页边距 180px，页眉 520px（标题 64px、班级 / 姓名 / 学号填写行 36px、说明 28px），数字格顶部 760px、格高 120px、格宽 `min(260, (2480-360-120)/Columns)`，整体水平居中。
- 列数 1–12（对应最长学号位数），行固定 0–9 共 10 行。左侧 0–9 行标，上方位值列标从个位到千亿，个位永远在最右，列数不足时取右侧 N 个。数字格外侧画实线边框，框选时只框数字格。
- 底部说明写明契约：「每列只涂一格；学号不足 N 位时左侧补 0；请用 2B 铅笔涂满方格」。数字按从左到右的高位到低位排列（最左为最高位），不足位数左侧补 0。
- CJK 字体按 `Microsoft YaHei → PingFang SC → Noto Sans CJK SC → Source Han Sans SC → SimHei` 回退，全找不到抛可读中文 `HomeworkException`；列数 0 / 13 同样抛异常。

### 区域选区（`NormalizedRect` / `NormalizedRectSelector`）

- 批次级 `HomeworkBatch.FillInRegion` 保存一份归一化矩形（0..1，左上角原点），单页可用 `FillInRegionOverride` 覆盖；`EffectiveFillInRegion(page)` 决定某页实际用哪一份。`SetFillInRegion` / `SetFillInColumns`（1–12）只在 `Editing` 态可改，`AutoColumns()` 取合格学号最长位数并夹到 1–12。
- `NormalizedRect.Clamp()` 拒绝非有限坐标并把四项夹到 0..1，`IsUsable` 要求宽高都不小于 0.02，`ToPixelRect(width, height)` 换算到像素矩形。
- 预览缩放先修好「缩放未绑定图像」：`PreviewPixelWidth/Height` 与 `PreviewDisplayWidth/Height`（像素 × `ZoomPercent/100`），预览 `Image` 放进 `Panel` 用 `Stretch=Fill`，框选控件与图像同尺寸，不做 `Stretch=Uniform` 的 letterbox 反算。
- 缩放范围 10–400%，`+/−` 按预设档位（10/15/20/25/33/50/67/75/80/90/100/110/125/150/175/200/250/300/400）跳档；缩放时保持视口中心，首次选中页自动适应一次，之后不覆盖老师手动调好的缩放。
- `NormalizedRectSelector` 自绘半透明填充 + 2px 边框 + 8 个白色方形手柄：空白处按下开始画、矩形内移动、手柄上缩放，坐标按控件尺寸归一化。纯几何 `RectSelectionMath` 处理 `FromDrag` / `Move` / `Resize` / `Clamp`，最小尺寸 0.02。

### 填涂检测（`FillInDetector`）

- 区域先 `Clamp()` 再按 `RegionInsetRatio=0.02` 内缩，均分 `columns × rows`（rows 固定 10），每格再按 `CellInsetRatio=0.15` 内缩以排除格线与行标。
- 灰度亮度 `0.299R + 0.587G + 0.114B` 低于 `InkLuminanceCutoff=180` 计为墨迹，算格内墨迹占比；每列取占比最大的行作为该列数字（0–9），置信度为该占比。
- 最大占比 < `MinInkRatio=0.15` 判「第 N 列没有涂黑」；次高 ≥ 最大 − `MinLeadRatio=0.10` 判「第 N 列涂了多格」。任一列失败整页失败并给出第一个失败列，空列不当作 0。
- 不做纠偏 / 自动旋转，不读格线或文字，不依赖真实扫描件；阈值与余量集中为 `FillInOptions` 常量，由合成图测试锁定。

### 学号解析（`FillInNumberResolver`）

- 只考虑 `Number` 非空且全为数字的学生。先按 `Ordinal` 精确匹配：命中 1 人 `Matched`，多于 1 人 `Ambiguous`。精确 0 人时双侧 `TrimStart('0')`（全零归一为 `"0"`）再匹配，1 人 `Matched`、多于 1 人 `Ambiguous`、0 人 `NoMatch`。
- `digits` 为空或全空白直接 `NoMatch`。歧义原因带班级名（调用方传 `batch.Classes.ToDictionary(c => c.Id, c => c.Name)`，查不到回退班级 Id），不按姓名匹配、不猜、不改名单。
- 跨班重复、空学号、非数字学号、无匹配都进待处理并写明原因；`PageRecognition` 用 `FailureReason` 表示「填涂没读出来」、`MatchFailureReason` 表示「读到了但无法唯一匹配」，两者都让该页留在待处理。

### 匹配不变量与撤销

- 只有唯一匹配、学生存在、且 `PagesOf(student).Count < ExpectedPagesPerStudent` 才自动 `Match`；绝不覆盖已有手动 `StudentId`，绝不给已交齐学生加页，绝不超出每人应交页数。
- 一次识别运行先算后写：逐页解码（图片走 `DecodePreview`，PDF 页走 PDFtoImage 200 DPI 后压长边到 2800）→ 检测 → 解析 → 收集结果，全部完成后**一次** `RecordChange("识别填涂", apply)`；取消时不 apply，状态「已取消，未改动」，不留半套匹配。
- `BatchEditSnapshot` 扩为 `(PageOrder, Matches, Recognitions)`，识别元数据纳入快照，一次运行一步撤销 / 重做，恢复时同时写回 `Recognition` 与 `StudentId`；保持「内容没变不入栈、恢复期间不入栈、100 步上限」。
- `HomeworkBatch.LoadRoster` 在清空匹配的同时清空所有 `Recognition`；名单重导后状态提示「请重新识别」，显式列数与新名单 `AutoColumns()` 不同时追加列数确认提示，绝不保留指向旧学生 ID 的识别结果。
- 长任务走 `Task.Run` + `IProgress<int>` + `CancellationToken` + 400ms 延迟的忙碌遮罩，失败与提前返回路径都收尾。提交门槛与第一阶段一致：未匹配页阻断，识别失败页自然留在待处理并带原因。

### 走查

- `--homework-fillin-shot <png> --homework-fillin-demo`（可与 `--width` 组合）：合成 3 名学号 001 / 002 / 003 的学生与 3 张已知数字的填涂页，框选数字格、列数 3，运行识别后截主窗口，并生成模板 PNG / PDF 校验几何。
- 状态写进 `<png>.state.txt`，字段为 `pages` / `recognized` / `matched` / `pending` / `columns` / `templatePng` / `templatePdfPages` / `window`；失败写 `<png>.error.txt`。合成姓名用苏晚晴 / 陈屿 / 许砚，无真实数据、不联网。

## 扫描任务（1.43.0）

- 两条路共用一个落点：`Homework.Core.Scanning` 的 `ScanSettings` / `ScanFileClassifier` / `ScanInboxWatcher` / `ScanTaskPreferences`；App 层 `IScannerService` / `IScanImportSink` / `ScanTaskViewModel` / `ScanTaskWindow`。扫描窗口不直接碰批次，导入由 `HomeworkWindow` 实现 `IScanImportSink`，当前批次或新建批次二选一。
- 驱动能力（1.44.0，A）：`ScannerCapabilities` + `WiaCapabilityReader` 读 `3086` / `3088`（来源）、`6146`（色彩）、`6147` / `6148`（分辨率）、`3097`（尺寸）、`3096`（最大页数）；界面只显示驱动报告的来源 / 尺寸 / 分辨率 / 色彩，未报告时列出全部选项供手动选择并提示；8K/16K 不在自动读取范围内（WIA 无标准枚举）；分辨率允许 75–1200，`ScanSettings.NormalizedForDriver()` 只做范围保护。平板在界面上叫「稿台玻璃」（与 Canon ScanGear 一致）。C（TWAIN）待决策见 `.memory/14-扫描驱动能力与TWAIN待决策.md`。
- 驱动界面扫描（B）：扫描窗口「用驱动界面扫描」按钮调 `WIA.CommonDialog.ShowAcquireImage` 的 `UseCommonUI=true`，弹驱动自己的设置界面（Windows 传真和扫描里那个），在那里选稿台玻璃 / 色彩 / DPI；扫完自动导入批次。用于 HUAWEI 这类不暴露 WIA 类型化属性的驱动；界面由驱动绘制，一次采集一张。
- Windows 直接扫描：`WiaScannerService` 走 WIA 自动化（`WIA.DeviceManager`），后台 STA 线程；`WiaScanRequest` 是纯映射（intent / X-Y resolution / document handling / pages / page size / extents），无硬件也能测。平板 = 2，输稿器单面 = 1，双面 = 1|4；黑白 = intent 4，灰度 = 2，彩色 = 1；8K / 16K 没有标准 WIA 枚举，用自定义 page size + 像素范围。逐页 PNG，失败回退 JPEG；输稿器最多 100 页；只支持 Windows，其他平台由 `ScannerServiceFactory` 返回 `UnsupportedScannerService`，界面明确引导到收件文件夹。需要安装扫描仪 WIA 驱动；ScanGear 2（TWAIN）本身不被直接调用。
- 收件文件夹：`ScanInboxWatcher` 用 `FileSystemWatcher` 监听 Created / Renamed，等文件大小连续两次一致且能以 `FileShare.Read` 打开才触发 `FileReady`；超时触发 `FileFailed`。过滤 `~$` / `~` / `.` 开头、`.tmp` / `.temp` / `.part` / `.crdownload`、`Thumbs.db` / `desktop.ini` / `.DS_Store`；只接受 `.png` / `.jpg` / `.jpeg` / `.bmp` / `.pdf`（`.tif` / `.tiff` 不在列，SKCodec 不支持解码）。手动「导入作业页」选择器也同步加了 `*.bmp`。同一路径 + 大小 + 最后写入时间只导入一次；监听启动时不自动导入旧文件，旧文件只由「导入现有文件」显式处理。事件在线程池线程触发，窗口用 `Dispatcher.UIThread.Post` 切回界面。
- 导入：`HomeworkWindow.ImportAsync` 在 `Task.Run` 里逐文件调用 `BatchWorkspaceViewModel.ImportPdf`（150 DPI 预览）或 `ImportImages`；每次导入新建一个 `PageThumbnailCache` 并挂到窗口的 `_caches`，关窗统一释放。扫描输出保存到 `%LOCALAPPDATA%\TeachCraft\Homework\Scans\<yyyyMMdd-HHmmss-fff>`，不删（导出要读源文件）；收件文件夹里的文件保持原位。
- 偏好：`ScanTaskPreferencesStore` 读写 `%LOCALAPPDATA%\TeachCraft\Homework\scan-task.json`，原子写；文件损坏 / 缺失回落默认值；只存本机，不进工程。`Normalized()` 修正空收件夹、分辨率 75–1200、平板强制仅第 1 页。
- UI：`ScanTaskWindow` 820×740（最小 720×640），原创纸墨卡片，两个页签「直接扫描 / 收件文件夹」；「导入到」卡置顶；直接扫描页有扫描仪下拉 + 刷新、扫描方式 / 原稿尺寸 / 分辨率 / 色彩 / 页面（页面跨两列，说明在网格下方）、状态与开始 / 取消；收件页有文件夹选择 / 打开 / 开始接收、接收记录（成功页数 + 批次，失败红字原因）、SMB 指引与复制路径。不是 Windows 传真和扫描的复刻。
- 不新增联网：WIA 与 FileSystemWatcher 都是本机；扫描件不经过任何网络服务。共享文件夹由操作系统负责，软件只读本地路径。
- 测试：`HomeworkScanSettingsTests` 22、`HomeworkScanFileClassifierTests` 21、`HomeworkScanTaskPreferencesTests` 4、`HomeworkWiaScanRequestTests` 5、`HomeworkScanInboxWatcherTests` 4、`HomeworkScanTaskViewModelTests` 11、`HomeworkWiaCapabilityReaderTests` 5，合计 75 项；全量 1645 项（非单实例 1640 项）。

## 共享名单拉取（1.45.0）

- **只拉取、不发布**：`src/Homework.Core/Roster/SharedRosterImport.cs` + `src/Homework.App/Cloud` 实现 `IHomeworkRosterBridge`。`HomeworkStudent` 没有性别字段，而共享名单必需姓名 / 性别 / 学号，所以作业整理只能拉取、不能发布；界面不提供上传入口。
- **多班拉取**：账号面板登录后手动拉取共享名单，可多选班级，合并进当前批次名单；同名班级要提示由用户确认，不静默覆盖已有班级的学生。
- **字段边界**：只取共享名单里已勾选并实际存在的字段；未勾选字段为 null，不写进本地名单也不进云端 JSON。性别缺口在拉取结果里如实标注，不编造性别。
- **不上传原始文件**：拉取只改内存中的批次名单，不上传原始作业页、不上传文件路径；原始文件只读这条不变量不因云同步改变。没有心跳、没有自动同步、没有定时器。
- **走查**：`--homework-roster-shot <png>` 渲染多班拉取状态，注入假 handler 与 Noop 凭据存储，不联网、不写真实 `Account/` 目录。
