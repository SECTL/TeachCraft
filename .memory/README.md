## 关键事实

- 产品名：**知微 · TeachCraft**；常备应用：**分晓 · GradeStrip**、**归位 · SeatGrid**、**时序 · ClassBlock**、**织序 · GradeWeave**、**竞名 · MeetRoster** 与 **辑册 · WorkFolio**。
- 技术栈：C# / .NET 10 + Avalonia 12.1.4，图片 SkiaSharp，PDF PDFsharp + PDFium，排版 QuestPDF，文档 OpenXml，名单 / 总表 ClosedXML / ExcelDataReader。
- 工具数：14 件小工具（图片处理 4 + 格式工厂 6 + 教学工具 4）+ 6 件常备应用（分晓、归位、时序、织序、竞名、辑册）。第 13 件为 `exam-paper-layout` 试卷排版，第 14 件为 `certificate-batch` 奖状生成。
- 版本基线：`1.46.0`，唯一版本源为 `Directory.Build.props`。`1.46.0` 完成 SECTL 集控中心接入（`platform: "teachcraft"`、v4 协议、默认关闭、侧栏「集控」面板、双因子/账号双通道接入与 8 条安全指令）；`1.45.0` 新增 SECTL 账号与共享名单（可选 OAuth 登录、字段级同意、归位发布 / 拉取、辑册拉取），联网边界扩为三处，本轮实测数量见 `07-验证与测试资产.md`（T11 填入）；`1.44.0` 让扫描选项按 WIA 驱动能力显示（只显示驱动报告的来源 / 尺寸 / 分辨率 / 色彩，未报告时用保守默认值）；`1.43.0` 为辑册新增「扫描任务」（Windows WIA 直接扫描 + 全平台收件文件夹，自动导入当前批次 / 新建批次），不新增联网；`1.42.0` 为第二阶段填涂识别（智学网式 A4 模板、矩形选区、确定性检测、学号唯一匹配、一步撤销），跨平台、无 OCR / 二维码；`1.41.0` 新增第 6 件常备应用「辑册」（原暂名「作业整理」，`homework`），第一阶段做图片 / PDF 导入、名单导入与手动匹配、四种导出；验证结果见 `07-验证与测试资产.md`。`1.40.1` 为奖状 UI 审计修复轮（实测 1256 项通过）。
- 奖状生成：底图 + XLSX / XLS 名单；工作表、表头行、姓名列与奖项列由用户明确指定，可选「（不印奖项）」。归一化文字位置与字号由预览和 PDF 共用，逐行生成 A4 PDF，全程本机处理，Core 拒绝覆盖底图或名单。
- 上一版验证基线（`1.40.0`，2026-11-21）：`dotnet test TeachCraft.slnx -c Release --no-restore`，工具箱 `TeachCraft.Tests` 962 项、分晓 `GradeStrip.Tests` 108 项、织序 `GradeWeave.Tests` 168 项，合计 1238 项全部通过；新增 6 项测试（取消 2 项、快照 / 待加载 4 项）。当时 Release 增量构建 0 警告、0 错误；测试工程干净编译仍有 2 条既存 xUnit2013 警告。奖状当时两组取证均为 3 条记录且导出通过，视觉验收仍为 INCONCLUSIVE（图像读取不受支持）。这些结果不代表本轮已验证，详见 `07-验证与测试资产.md`。
- 仓库：`https://github.com/SECTL/TeachCraft`（2026-11-08 从 `Evan0148/TeachCraft` 迁来；老地址 301 但 API 跟随行为不可靠，代码里的地址必须写新仓库）。
- 隐私：文件在本机处理；联网只有三处、都由用户明确开启——「检查更新」读取版本号（GitHub Releases 或用户选定的 SECTL 镜像）、「账号与云同步」在主动登录 SECTL 后手动发布 / 拉取共享名单与关联座位表，以及主动开启「启用 SECTL 集控」后保持一条 WebSocket 长连接接收大屏展示指令与只读摘要查询（不传学生姓名、学号与成绩）。三处默认关闭，关闭时不建立连接、不发送任何文件；云同步不做心跳、不上传原始文件；归位座位表另有可选的「自动同步」（默认关闭、事件触发、无定时器）。
