# 04 · 界面设计系统

设计语言直接继承「分晓 · GradeStrip」：Anthropic 的纸墨感、衬线标题、等宽编号、细边白卡、陶土色点缀。

## 色板

| 语义 | 色值 | 用途 |
| :--- | :--- | :--- |
| Ink | `#141413` | 主文字、主按钮、标题 |
| InkSoft | `#3D3B36` | 正文 |
| Muted | `#6F6A5E` | 辅助文字、标签（on Paper 5.11:1） |
| Paper | `#FAF9F5` | 窗口底色 |
| PaperDeep | `#F4F2EC` | 提示块、轨道 |

| Line | `#E7E3D8` | 1px 描边 / 分隔线 |
| Accent | `#D97757` | 陶土色点缀、进度、强调 |
| AccentDeep | `#A34A36` | 链接、错误、编号（on Paper 5.55:1，小字达 AA） |
| Moss | `#5A7A4B` | 成功状态 |
| Tier1–5 | `#70AD47` `#C6E0B4` `#DDEBF7` `#FFF2CC` `#F8CBAD` | 成绩条 / 迷你预览 |

Fluent 控件强调色统一覆盖为 `SystemAccentColor = #D97757`，避免默认蓝色滑杆破坏配色。

## 尺寸与布局

- 窗口 1200×840，最小 1120×720；侧栏固定 232；内容最大宽 1104。
- 课堂工具窗（归位 / 时序 / 织序）1440×920，最小 1120×680；所有窗口打开时由 `src/Shared/WindowFit.Clamp` 钳进当前屏幕工作区（按 `Screen.Scaling` 在 DIP 与物理像素间换算，最小尺寸会先让路）。
- 卡片圆角 10（工具）/ 12（常备）；按钮与输入 6–8；抽屉宽 452。
- 工具卡双列，`UniformGrid Columns=2`，卡内 44px 字形方块 + 编号/ID + 名称 + 描述。
- 常备卡：五张同款行卡（44px 字形块 + 编号 / 名称 + 一句话描述 + 状态 + 打开应用 + 展开箭头），不再有单独的大卡与暖色底；分晓的成绩条预览（`StripPreview`，360px）与「项目详情」放在点开后的说明区右侧，说明与要点 chip 只出一份（来自 `ToolDescriptionCatalog`）。

## 组件与样式

- `Button.tool-card`：自定义模板（无 Fluent 默认底色），悬停描边加深、底色转暖白，字形块转陶土。
- `Button.nav`：文字式导航，选中底色 `#F1EEE5` + 左侧 2px 陶土条。
- `Button.dropzone`：透明模板 + `Rectangle` 虚线框（`StrokeDashArray 5,4`）。
- `Button.panel-close` / `Button.mini`：小尺寸轻量按钮。
- `Border.card` / `Border.chip` / `Border.panel`：细边、无阴影。
- `Slider`（全局，`App.axaml`）：2px `LineStrong` 轨道 + 陶土已填充段 + 15px 墨边纸面圆钮，行高 24；悬停 / 键盘聚焦时圆钮转陶土描边，禁用转 Muted。选择器必须写 `Slider:horizontal`，不带伪类压不过 Fluent 主题（见 06）。标签与滑块成对放进 `Spacing=4` 的 StackPanel，多组之间留更大间距。
- 状态栏：左侧状态圆点 + 文案（超长省略 + ToolTip），有新版时中间出现非阻塞提示条（更新 / 稍后），右侧 `V1.17.0 · 10 TOOLS · 5 APPS`。「检查更新」入口不在状态栏，在侧栏底部：LOCAL ONLY 联网说明与版本号之间，`nav nav-action` 按钮 + 刷新图标，与说明文字左对齐。

## 动效

| 场景 | 时长 / 曲线 |
| :--- | :--- |
| 卡片悬停 | 160ms，背景 / 描边颜色过渡 |
| 按压 | 80ms `CircularEaseOut`，`scale(0.97)` |
| 工具卡说明展开 / 收起 | 260ms `EaseOutCubic`，高度 0→自然高度 + 透明度 0→1，可中途反向 |
| 抽屉推入 | 320ms `CubicEaseOut`，X 452→0 + 透明度 0→1 |
| 抽屉退出 | 240ms `CubicEaseIn` |
| 遮罩 | 260ms 淡入 / 200ms 淡出 |
| 页面切换 | 160–200ms 淡入 |

## 工具说明展开（1.16.0）

每张工具卡与案头常备卡都能展开一段完整说明（一句话定位、功能要点 chip、输入 / 输出 / 处理方式、三条功能摘要），**默认全部收起**，点卡片或卡片标题才展开；右键菜单式的常驻说明会让工作台一屏塞不下 10 张卡。

- 数据层：`src/TeachCraft.App/ViewModels/ToolDescription.cs` 与 `ToolDescriptionCatalog.cs`，以工具 ID / 常备 key 为键，是文案的唯一来源；界面只绑定，不在 XAML 里再写一份。
- 说明文案同时进入搜索命中面（例如搜 `EXIF` 能命中「图片格式转换」与「图片尺寸调整」）。
- 展开控件：`src/TeachCraft.App/Controls/ExpandReveal.cs`，先按当前宽度量出子内容自然高度（约束高度为无限），再逐帧只改自身高度并 `ClipToBounds` 裁切，文字不会因为高度被压而逐行跳动。
- 动画只改高度、透明度与命中测试，不动 `RenderTransform`，因此不会和 `Button` 基类的按压回弹抢同一个属性。系统开启「减弱动效」时（`MotionPreference.ReduceMotion`）直接落位，不做逐帧动画。
- 工具卡从 `Button` 改为 `Border.tool-card`：卡内要放「打开」按钮与可展开区，嵌套 `Button` 会互相吞掉点击与键盘焦点。点卡内按钮时守卫 `FindAncestorOfType<Button>` 直接放行，不触发展开切换。
- 点「卡片本体」与点「标题」走同一条路径：标题只是卡内元素，`PointerPressed` 冒泡到卡片根 `Border` 后统一处理，因此标题不需要单独挂处理器（`--title-click` 走查证明冒泡 `handled=True`）。键盘上卡片 `Focusable=True`，聚焦后 `Enter` / 空格切换。
- 展开态必须「看得见」：`Border.tool-card.expanded` 换暖白底 `HighlightBrush` + 陶土描边 `HighlightLineBrush`，标题转 `AccentDeep` 并加下划线，右侧箭头翻 180°。注意两条 Avalonia 优先级规则——XAML 局部属性值会压过样式（所以常备卡的 `Background` / `BorderBrush` 改由 `Border.app-card` 样式提供），全局 `TextBlock` 样式会压过后代选择器（所以标题的 `.expanded` 必须直接挂在 `TextBlock` 上）。
- 卡片双列改用 `WrapPanel` + `ColumnWidthConverter.TwoColumns` 定宽，不再用 `UniformGrid`：后者会把同一行两张卡拉成等高，一张展开就在另一张下面留一大块空白。卡还要 `VerticalAlignment=Top`，否则 `WrapPanel` 仍会把同行元素拉到行高。
- 展开后等待揭示动画同长（300ms）再按最终 `Bounds` 做「最少必要」滚动，保证说明区不会被窗口底边切掉；整张卡已完整可见时不动滚动条。
- 走查探针与窗口行为分开：`MainWindow.axaml.cs` 只留产品逻辑（抽屉动效、导航、文件选择、卡片展开滚动），所有 `--shot` / `--expand-*` / `--interact` 等取证方法放在 `MainWindow.Diagnostics.cs`（`partial class MainWindow`），沿用 `SeatGridDiagnostics` 的既有做法。滚动定时器 `_revealScrollTimer` 属于产品逻辑，留在主文件。

## 与 HTML 视觉稿的差异

- HTML 稿（`design-preview/`）是评审基准；C# 版按桌面窗口实际尺寸重排，未保留右侧竖排边注。
- 原生文件/文件夹选择器取代了 Web 的拖放上传，抽屉仍是同一套版式。
- 工具编号从 HTML 的 09–18 调整为 01–10（因为只收录图中这 10 件），工具 ID 原样保留。
- 增加文件选择后的有序列表、结果「打开所在文件夹」、真实进度与错误色。

## 应用图标

- 知微主图标为纸色圆角方块 + 墨色条块 + 陶土竖线；侧栏、卡片与窗口标题统一使用这一几何网格语言。
- 分晓、归位、时序各有独立图标（成绩条 / 座位网格 / 课程表），侧栏与常备卡使用内联 `Canvas` 版本，缩放不失真。
- 可执行文件与安装包图标在 `src/TeachCraft.App/Assets`、`src/SeatGrid.App/Assets`、`src/ClassBlock.App/Assets`；设计稿与备选方案在 `design/logo/` 下。
- 窗口 `Icon` 统一使用 `avares://TeachCraft/Assets/...` 绝对资源路径，避免相对路径在不同入口下解析失败。

## 无障碍

- 所有工具卡暴露名称；侧栏四项导航设置 `AutomationProperties.Name`；投放区、开始处理按钮同样有名称。
- 辅助文字统一 `MutedBrush = #6F6A5E`（on Paper 5.11:1），错误文字用 `AccentDeepBrush = #A34A36`（5.55:1）；不再使用 `#9C9585 / #A29C8C / #8E8776 / #B0AA9C` 等散值。
- 动效克制，不使用弹跳或大幅位移。
