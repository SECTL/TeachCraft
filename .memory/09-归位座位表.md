# 09 · 归位 · SeatGrid

## 目标

在「知微」工具箱里新增一只座位表应用：老师导入一份普通名单（xlsx / xls / csv），软件自动识别姓名、性别以及身高、视力等座位信息，按参考图的设置排座、预览、打印，并导出 Excel 与 PNG。

## 数据管线

```
RosterImporter → SeatingEngine → SeatChartComposer → SeatChartRenderer (PNG / PDF)
                                              ├→ SeatChartExcelExporter
                                              └→ SeatGridConfigIO
```

界面、PNG、PDF、Excel 共用同一个 `SeatChartDocument`，避免「预览与打印不是同一张表」。

## 名单识别

- 读取：`ExcelDataReader` 统一处理 xlsx / xls / csv；xls 通过 `CodePagesEncodingProvider` 兼容 GBK。
- 表头：扫描前 20 行，按「姓名 / 性别 / 学号 / 身高 / 视力 / 成绩 / 小组 / 备注」同义词打分，取匹配最多的一行。
- 无表头：按内容识别姓名列（中文 2–6 字或拉丁姓名）与性别列（男/女、M/F、1/0）。
- 容错：跳过空姓名、合计、平均、表头行；处理「张三(男)」、姓名后追加性别、身高 1.75（米）→ 175（厘米）、视力 5.0/4.8 → 取较差值。
- 结果附带 warnings（无性别列、重名、跳过行），导入后显示在状态栏。

## 教室画布（1.26.0）

- **`SeatChartCanvas`**（`src/SeatGrid.Core/Models/`）：不可变画布，承载 `DisabledSeats`（过道格，`FrozenSet`）、`RowCorridors` / `ColumnCorridors` / `GroupCorridors`（逐边界过道宽度，单位「格」）、`Doors`（门窗）。所有变换返回新实例——`SeatChartSettings.Clone()` 是浅拷贝，靠不可变性保证共享安全。用 `FrozenSet` 而不是 `HashSet`：`ComposeDocument` / `RenderPng` 在后台线程跑，UI 线程可能同时在改。
- **`SeatChartLayout`** 主构造加可选 `SeatChartCanvas? Canvas = null`（现有构造点零改动）。新增 `Surface` / `CellCount` / `UsableSeatCount` / `IsUsable` / `AllUsableSeats`；`FillOrder` 过滤过道，`AllSeats` 不过滤（画布要画满矩形）。`SeatCount` 保留为 `UsableSeatCount` 的别名。
- **`SeatChartGeometry`**（`Rendering/`）是几何的唯一真相。此前有三份互不相等的副本——XAML 的 `Spacing=6/22`、`UpdatePodium` 的硬编码、Renderer 的 `cell*0.07 / cell*0.28`（`0.07*80=5.6 ≠ 6`）。现在界面、PNG / PDF、Excel 全部读它，偏移数组按**显示序**生成（学生视角排是倒的，按物理序算再倒着画会让排距跑到最前面）。
- 默认间距：列距 7%、组距 28%、排距 7%（与旧渲染器一致）；逐边界过道在默认值之上叠加。**过道挂在它后面那一段上，即使那是最后一段也要算**，否则走廊在表尾会消失。
- **阶梯教室**只加一个 `TierRowGrowthPercent` 标量。深度一律按**物理排号**算——教师视角的显示序是倒的（讲台在下），用显示序下标会让阶梯反向。
- **门窗**：`RoomDoor(Edge, OffsetRatio, Label)`，边缘枚举 + 0–1 比例（绝对坐标在改布局后必然失效）。UI 只提供 Front / Back（覆盖 99% 场景），Left / Right 留在模型与导出里。**Excel 端只能落成文字行**（ClosedXML 无形状 API），PNG / PDF 画门洞线段——形态差异是刻意的降级，不是 bug。
- **讲台**：倾角**不做**（Excel 无形状 API，同一文档两种形态违反 AGENTS；零信息量）；位置**不是自由参数**（`Row=0` 是靠讲台第一排，挪走会让「前排」失去物理意义）。可调的是 `PodiumLabel` / `PodiumWidthPercent` / `PodiumHeight`。
- **持久化**：画布序列化成一个 JSON 单元格（`SeatChartCanvasCodec`，`{V, Aisles, RowGaps, ColumnGaps, GroupGaps, Doors}`），与八个标量一起进「座位设置」表。缺键即空画布、**不报警告**。**Marker 仍是 v1**。
- **画布编辑器**（`SeatCanvasEditorWindow`）做成独立窗口，不塞进主窗口——主窗口指针已被 Seat/Row/Column 三态拖拽状态机占用，第四种「刷子」模式会打架。

## 考务套件（1.27.0）

- **考场模式**：独立的考场快照，不改日常 `_assignments`、不改 `ViewMode`。`ExamPlanner` 按人数算单人桌布局——列数 `clamp(ceil(sqrt(N)), 1, MaxColumns)`（默认上限 8），排数向上取整；座号蛇形（逐排往返）或按列。进出考场时 `CurrentLayout` 在考场模式下直接返回 `_examPlan.Layout`，**不改日常的组/排/列滑块值**（否则界面显示 4 列而实际 7 列）。考场下锁定 / 互斥 / 结对 / 区域不生效并明说。返回日常时从内存快照整体还原。
- **桌贴打印**：`DeskStickerRenderer` 画 A4 纵向 3×4=12 张/页，每张印姓名、座号、考号、班级与考场，四周虚线裁切线；`DeskStickerPdfExporter` 沿用「Skia 画 PNG → QuestPDF 嵌 A4」管线。**不做条码**——收益低于把考号放大；要加时在渲染器里加一个分支即可。桌贴设置窗（`DeskStickerOptionsWindow`）左设置右预览、200ms 防抖、关窗取消在途渲染。
- **周轮转**：`SeatChartComposer.RotateGroups` 只换 `Group`，`Row` / `Column` 不动，最外侧绕回；目标格是过道时学生留在原组并报数；锁定跟随学生（`ReplacePins`）。与「整班平移」（屏幕方向平移，行列都动）严格区分，考场视图下禁用。
- **桌椅搬运量**：`DeskMovingPlanCalculator` 只给静态指引（保留 / 搬出 / 补进 + 逐排），不做路径动画——软件没有教室平面图，路径一定是假的。

## 考场导出与座号（1.32.0，踩坑记）

- **踩过的坑：`ComposeDocument` 走了 `ToSettings()`**。界面网格读 `CurrentLayout`（考场下返回 `_examPlan.Layout`），而 `ComposeDocument` 一直是 `Compose(ToSettings(), …)`——`ToSettings()` 的组 / 排 / 列取自**日常滑块**，`Compose` 开头又调 `Normalize()` 把 `Columns` 夹到 4。30 人考场 6 列 × 5 排被切成 4 列 × N 排，后排学生整片消失，**而且不报错**：文档结构完全合法，只是少了一截。PNG / PDF / Excel / PPTX 共用这份文档，一坏全坏。教训是「界面与导出共用一份文档」只保证了**形状一致**，没保证**布局来源一致**——两处各自读布局时，测试只断言「导出能跑通」是照不出来的。
- **修法：`SeatChartSettings.LayoutOverride`**。`GetLayout()` 有显式布局就返回它，根本读不到那三个被夹取的字段；`Normalize()` **一个字没改**，夹取是给日常滑块用的不变量。唯一例外是 `Canvas = Canvas.Normalize(GetLayout())` 那一行加了 `LayoutOverride is null` 守卫——否则会拿考场尺寸去截日常画布，而 `ToSettings()` 交出去的是同一个 `SeatChartCanvas` 引用，截掉就回不来（守护测试把过道放在第 2 组、考场只有 1 组来照这个）。
- **座号**：`SeatChartDocument.SeatNumbers`（`SeatPosition` → 1 基座号）配 `DisplaySeat.SeatNumber`。**座号属于座位不属于人**，空座也编号（老师要按号布置考桌），所以画在 `IsEmpty` 提前返回之前。日常表是空表，四条导出都判空跳过；已核对 PNG 字节、PDF 内容流、xlsx 表内容、pptx 幻灯片 XML 与修复前一致，只有 OOXML 的随机关系 ID 与时间戳不同。画法：格子左上角、取 `RowLabel` 灰、字号 `clamp(格宽 × 0.16, 7, 11)`；Excel 走富文本（姓名 + 换行小号座号，**样式先写、文字后写**），PPTX 加一个无填充小文本框。
- **配置语义**：考场导出会带隐藏「座位设置」表（与日常同格式），但多写一行 `ExamSnapshot=true`。「导出配置」在考场下**直接禁用**（Core 的 `SeatGridConfigIO.Export` 见 `LayoutOverride` 也再抛一道，挡住脚本 / 批处理入口）；导入侧见到标记**如实抛中文错误**，不产出「导回来变成日常布局」的配置。隐藏设置表里的组 / 排 / 列写**考场自己的**（1 × 5 × 6），不是日常滑块的 4 × 6 × 2——文件导不回去也不能自相矛盾，否则打开文件的人看到设置写 4 组、画面上 1 组，只会以为软件坏了。约束表在考场导出里不写——考场下锁定 / 互斥 / 结对 / 区域本就不生效。
- **守护测试** `SeatGridExamExportTests`（24 项）：30 人考场断言 `Columns == 6 / Rows == 5 / 座位 30 / 座号 1..30 蛇形`；日常断言 `ComposeDocument` 与旧写法逐字段一致、座号表为空、xlsx 无 `ExamSnapshot`；Normalize 断言日常夹取仍在、带显式布局时 `GetLayout()` 不被改写、日常画布不被截。**测试为什么不需要无头 Avalonia**：`SeatCellViewModel.Update` 会用 `FormattedText` 量姓名宽度，没有字体后端会抛「Unable to locate 'Avalonia.Platform.IFontManagerImpl'」。第一版为此引入了 `Avalonia.Headless`，结果很糟：Avalonia 把 `Dispatcher.UIThread` 焊死在初始化它的线程上，而 xUnit 各测试类跑在不同线程，全量跑随机炸「The calling thread cannot access this object」（3 次里挂 1 次），换成专用 UI 线程 + `ModuleInitializer` 又把测试主机跑崩。**正确修法是让量宽失败不要致命**：`FitFontSize` 量不出来就原样返回字号——那只是「量不出来」，不是「这个座位坏了」，不该掀掉整次 `RefreshSeatVisuals`。测试因此完全不依赖 Avalonia。
- **走查**：`--seatgrid-shot out.png exam-packed`（30 人正好铺满 6 × 5）与 `--seatgrid-chart-export <路径> [excel]`（截窗口的同时把导出用的那份文档真渲染一遍——只截界面看不出导出错）。

## 清空画布（1.33.1）

- **踩过的坑：`ClearCanvas()` 有方法没入口**。右侧「教室画布」节只放了「编辑画布…」与四个快速形状按钮，`ClearCanvas()` 虽然存在却没人调用。于是点过 U 型 / 多岛之后，中间那片虚线空格只能开编辑器一格一格刷回座位——或者靠 1.33.0 才有的撤销。现在「编辑画布…」右边并排一个「清空画布」，`CanClearCanvas`（`IsIdle && !Canvas.IsEmpty`）在画布本来就空时置灰，避免点了没反应的按钮。
- **那片「大间距」不是间距**：它是 `SeatChartCanvas.DisabledSeats` 里的过道标记，U 型预设把中间组靠讲台的前若干排整片设成不坐人，再加宽一条组间走廊。删它只有两条路——清空整个画布，或者在编辑器里逐格刷回。面板摘要「N 格 · M 座 · K 处过道」里的 K 就是它。
- 清空走 `ApplyCanvas`，因此 1.33.0 的撤销能一次撤回；被过道挤下来的学生仍按既有逻辑退回未排并报数。

## 撤销 / 重做（1.33.0）

- **为什么是整份快照而不是命令对象**：归位有 30 来处会改数据的入口（自动排座、拖拽、平移、镜像、轮转、末尾增删、画布、约束、名单增删改、进出考场）。逐条写一对 Do/Undo 既容易漏，也容易在「撤销时依赖已被改掉的状态」上出错。快照是 O(座位数 + 人数) 的扁平拷贝，一个班几十到上百人，代价可以忽略；换来的是「任何入口都没忘记登记」这条更强的保证。
- **唯一登记点是 `RecordChange(label, action)`**：**先拍照再改**（`change()` 里任何判断提前返回都不影响已拍的快照，拍快照本身不会失败）。窗口层的约束弹窗 / 画布编辑器走 `RecordWindowChange`，否则那些改动撤不回去。
- **撤销 / 重做自身不入栈**：恢复期间 `_restoring = true`，`RecordChange` 直接执行不再登记。不设这个标志会越按越多、永远退不出去。
- **快照只存数据不存 ViewModel**：学生用新增的 `Student.CopyKeepingId()`——`Student` 是普通类不能用 `with`，而普通 `Copy()` 会换 Id，座位与约束全部错位。座位存 `SeatPosition → Guid`，恢复时按 Id 复用现有 ViewModel，**不新造**：新造会让「已选中学生」与右侧编辑框和刚撤销回来的数据脱钩。
- **考场必须进快照**：考场把 `CurrentLayout` 整体换成 `_examPlan.Layout`。只还原座位与布局而不还原 `IsExamMode`，座位已经是日常的、界面却还按考场画，撤销看起来就像没生效。所以 `SeatStateSnapshot` 带 `IsExam` 与 `ExamPlanSnapshot`。
- **四条语义**：① 内容没变不入栈（滑块同一档位连发、点了没反应的按钮都不该占一步），比对用 `ContentEquals` 且**不含 Label**；② 撤销后新改动清空重做栈（标准编辑器语义）；③ 超出 100 步**丢最老的一步**而不是停止记录——停止记录等于「按了没反应」，比丢最老更让人困惑；④ `LoadRoster` / `ApplyConfig` 是「换了一份数据」不是「编辑」，整段 `_suspendUndo = true` 并在末尾清栈（内部的 `AutoArrange` 也不该单独成一步）。
- **界面**：顶栏标题右侧「↶ 撤销 / ↷ 重做」，`CanUndo` / `CanRedo` 同时受 `IsBusy` 约束。快捷键 `Ctrl+Z` 撤销、`Ctrl+Y` 与 `Ctrl+Shift+Z` 都重做；**焦点在 `TextBox` 里时让给文本框自己的撤销**，抢过来会让人没法改姓名 / 学号。
- **走查**：`--seatgrid-shot <png> undo`（撤销可点、重做灰）与 `redo`（反之）。两张截图用像素比对验过：可点态文字是 `#141413`（R≈20），禁用态是 `#B3AD9E`（R≈179）。

## 空间变换与异形教室（1.28.0）

- **末尾增删**：`AppendRow / AppendColumn / AppendGroup` 只扩边界、不动学生，无需确认；`RemoveLastRow / RemoveLastColumn / RemoveLastGroup` 返回被挤掉的坐标，由调用方退回未排并报数。**只允许删末尾**——删中间排要重新编号，而 `Row = 0` 是物理不变量；要删中间一排时，正确做法是把人挪走再把那排标成过道。
- **镜像**：`MirrorColumns`（每组内左右翻转）与 `MirrorGroups`（组序翻转）是**数据变换**，与学生视角的展示旋转严格区分——前者真的把学生换位置，后者不改数据。目标格是过道时该学生留在原地并报数。
- **整班平移**：`ShiftOnScreen` 加 `out int blocked`；目标格是过道时原地不动（继续往后找会让不同学生挪的格数不同、相对顺序被打乱，比不动更糟）。
- **异形教室预设**（`SeatCanvasPresets`）：U 型 / 多岛 / 长短排 / 报告厅，都是**纯函数产出普通 canvas**，不是新的「形状」概念——所以零持久化成本，也不会与手工改的格子失配。布局太小时返回 null，不产出半张图。应用前若有既有过道标记要确认。
- **区域限制**：「排座约束」节提供「只在前 2 排 / 避开后 2 排 / 清除」三键，作用于当前选中的学生。`StudentZone` 早就在 1.25.0 落地，这批补的是快捷入口。

## 交互与格式（1.29.0）

- **小组导师制**：`MentorPlanner` 选组内成绩最高者为组长（同分按名单顺序），组长座默认组中心、可选第一排；组员按切比雪夫距离环绕。**纯软约束**——只影响「谁更优先拿到候选座」，绝不推翻锁定、区域、互斥与结对。组长是算出来的，**不持久化**（`Student.Id` 不稳定）；导出不画组长标记。
- **拼音快速找人**：`TinyPinyin.Net`（MIT，纯托管）在 `StudentViewModel` 构造时预计算全拼与首字母，追加进 `SearchKey`。双击座位打开 `QuickSwapWindow`，输入姓名或 `ZS` 即可对调；重名时显示「姓名 · 座位 · 学号」并要求再输入几个字缩小范围。拼音取不到读音时原样保留，不影响按姓名搜。
- **全屏投影**：`SeatProjectionWindow` 无边框全屏，直接绑定同一个 VM（不新建文档），整张表用 `Viewbox` 缩放；Esc 退出、←/→ 切换视角。
- **PPTX 导出**：`SeatChartPptxExporter` 单页 16:9，文字为主。**PPTX 的最小可用结构是母版 + 版式 + 主题**——缺任何一个 PowerPoint 都会报「需要修复」，而 SDK 不会替你补。座位顺序必须复用 `GroupOrder / ColumnOrder / RowOrder`。PPTX 只画座位，不含未排座的学生。
- **导入增强**：列别名扩充（`学生姓名` / `总成绩` / `分组` / `Score` / `座号` 等），并在有表头时把**认不出的列名列出来**——老师至少知道哪些信息被忽略了。

## 座位模型

- 物理坐标 `SeatPosition(Group, Row, Column)`；`Row = 0` 永远是靠近讲台的第一排。- 教师视角：讲台在下、第一排靠下；学生视角：整体旋转 180°，讲台在上、第一排靠上。视角只影响展示，不改变座位。旋转 180° 意味着组序、组内列序、排序一起反转（同桌左右也对调）；摆放顺序只由 `SeatChartComposer.GroupOrder / ColumnOrder / RowOrder` 给出，界面网格、列把手、PNG / PDF / Excel 与整班平移（`ShiftOnScreen`）共用。
- **同桌与邻座（1.25.0 起显式化）**：`SeatChartLayout.DeskmateOf / AreDeskmates` 定义同桌——同组同排、列号落在同一对双人桌（`col / 2` 相同），不跨组、不跨排；`Columns = 1` 没有同桌，`Columns = 3` 的第 3 列落单。`NeighborsOf / AreAdjacent` 定义邻座——前后左右，**不跨组**（组间是过道）、不含对角。
  - 这次修掉一个既有缺陷：旧 `GenderPair` 靠 `FillOrder` 的列循环「碰巧」成对，`Columns = 3` 时第 3 列会与**下一排第 1 列**配成同桌（物理上根本不在一起）。现在改为按 `DeskmateOf` 成对，属**行为变更**，已写进版本说明。
- 自动排座填充顺序：先填第一排，再从左到右跨组，然后逐排向后；这样「按身高 / 按视力」的前排优先才成立。
- 排座方式（1.25.0 起 8 种）：名单顺序、男女交替（异性同桌）、同性同桌（`ArrangeMode.GenderPair`，按 `DeskmateOf` 成对）、随机、按身高、按视力、**成绩均衡（`ScoreSnake`，蛇形分桶）**、**成绩分层（`ScoreLayers`，每组等高/中/低）**。枚举顺序 = 下拉顺序，`AutoArrange` 的 Clamp 上限随 `ArrangeModes.Count` 走。
- **约束引擎（1.25.0）**：`SeatingEngine.Arrange(students, layout, mode, ArrangeConstraints)` 返回 `ArrangeResult`（座位 + `Issues` + 未排座学生）。四步：固定点预占 → 约束感知贪心 → 局部修复（≤4 轮两两交换）→ 报告。不做通用 CSP，规模上界 80 人 / 320 座，毫秒级。
  - **锁定**（`Pins`）：锁的是「学生-座位绑定」，重排时该学生不动。布局缩小 / 删学生时同步清锁并报数；`ClearSeats` 保留锁定；手动移动 / 平移 / 整排整列对调遇到锁定**整体拒绝**（不是跳过）。
  - **绝不相邻**（`Mutex`）：贪心阶段跳过会挨着的候选座，全部违反时取违反数最少者并落 `MutexUnsatisfied`。
  - **必须同桌**（`Deskmates`）：`SeatUnit` 双人成块；找不到双人桌时三层降级（双人桌 → 各自单人），每层都落 issue。
  - **上期同桌**（`AvoidDeskmates`）：软约束，尽量不重复安排；与硬约束冲突时让路并如实报告。
  - **区域限制**（`Zones`）：`SeatRect` 允许 ∩ 减 禁止。**先过滤、后排优先**——区域只裁剪候选集、不参与排序，所以被限制在第 3–6 排的矮个子仍落在第 3 排最靠前。
  - **成绩模式**：蛇形分桶保证各组均分接近；组内默认「高低交替（Fold）」，避免前排变高分区。
  - **排座说明**：`ArrangeResult.Issues` 的每条中文提示进状态栏（首条 + 「另有 N 条」）与右侧「排座约束」节底部的 Expander，不新建窗口。
- **持久化**：隐藏工作表「座位约束」（12 列：类型 / 学生A / 学生B / 组起止 / 排起止 / 列起止 / 说明 / 名单序号）。学生按「名单序号 + 姓名」双校验定位——`Student.Id` 每次导入都重新生成，**绝不能当持久键**。「座位设置」表新增 `ArrangeMode` / `WithinGroupOrder` 两个标量键。**Marker 仍为 `SeatGrid Config v1`**：判据是「旧版读者会不会产出错误结果」而非「有没有新字段」；升 v2 反而会让旧版掉进 `InferLegacyChartSettings` 去误推布局。
- 自动排座弹窗：点「自动排座」先弹「同桌之间按哪种性别方式安排？」（`SeatGridWindow.ShowArrangeGenderDialogAsync`），异性同桌 → 男女交替、同性同桌 → 同性同桌，选中后同步下拉框再排座；当前方式为名单顺序/随机/按身高/按视力时弹窗补「按当前方式「…」排座」直达，取消则不动座位。弹窗样式与 `ConfirmDialog` 同一套纸墨色板（#FAF9F5/#141413/#E7E3D8/#C6613F）。
- 手动：点击座位选中 → 左侧选学生 →「放入所选学生」；已坐学生会被移动，目标座位原学生自动变为未排；可「清空座位」。
- 拖拽：按住有人卡片拖到另一座位——目标有人则对调、空位则移动（6px 阈值内视为点击）。座位是 Button，会吃掉指针事件，拖拽统一在窗口层用 `AddHandler(..., RoutingStrategies.Tunnel, handledEventsToo: true)` 接管（1.3.x 修复）。
- 行列调整：设置面板「调整行列」卡可整班平移（左右上下，边缘绕回，方向按当前视角换算）；行首排号把手拖动整排对调、列尾 ⠿ 把手拖动整列对调（可跨组），窗口层同一状态机按 Tag 分流 Seat/Row/Column 三种模式。
- 重复占座不允许；学生人数超过座位时，多余学生保持未排。

## 导出

- **预览 / PNG**：SkiaSharp 渲染，默认 2x；图片与打印使用同一份 composer 结果。
- **PDF**：先渲染约 3200px 长边的高分辨率 PNG，再用 QuestPDF 放入 A4 横向/纵向，避免 SkiaSharp PDF 内嵌整套中文字体（曾达 23MB；现在约 0.4MB）。
- **Excel**：ClosedXML 生成带颜色、边框、合并标题的「座位表」+「名单」两张表；性别、学号、身高、视力、成绩、备注与座位位置全部保留。另附一张隐藏的「座位设置」（与配置文件同格式），所以导出的座位表能从「导入名单」或「导入配置」导回继续修改：名单、座位、布局、配色与标题整体还原，不重新自动排座。没有隐藏表的旧版导出按名单页的组 / 排 / 列还原座位，布局由组 / 排标题推算，配色与字号用默认值并在状态栏说明。
- **配置**：`SeatGridConfigIO` 导出/导入设置、名单与座位；导入时校验布局范围与重复座位。
- **打印**：生成临时 PDF 并用系统默认阅读器打开，由老师确认后打印。
- **保护**：任何导出路径与已导入的名单路径相同都会被拒绝，避免覆盖源文件。

## 已知边界

- 复杂合并表头只识别单行表头；多行表头可能需用户先整理。
- 加密 xlsx 无法读取，会给出中文错误。
- PDF 为高分辨率位图，文字不可选中；需要可编辑文本请用「导出 Excel」。
- 暂不支持撤销/重做、多班级切换。
- 打印依赖系统默认 PDF 阅读器；未集成系统原生打印对话框。
