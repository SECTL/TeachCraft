# 08 · 待办与后续

## 已知边界（非缺陷）

- Word→PDF 不渲染 DOCX 内嵌图片、页眉页脚、分栏、浮动对象。
- PDF→Word 文字模式丢失复杂版式；需要版式时用「保留版面」。
- PNG 压缩不降画质，体积收益来自缩小边长。
- 加密 PDF 不做破解，提示用户先解除密码。
- 归位：复杂多行表头只识别单行；加密 xlsx 无法读取；打印 PDF 为位图；暂无拖拽、撤销/重做、多班级切换。
- 时序：只支持 xlsx；只识别「一表多班」结构；只取第一张满足条件的课程表；时间行为固定模板（改作息需改代码）；打印 PDF 为位图；暂无 Excel 导出与多班级批量导出。
- 织序（首版）：单年级、五天 × 7 节；只读 xlsx；课服 / 晚修仅作为扩展时段，不自动编排；分层走班只建模 A/B 两层，暂不导入 B 层学生名单；不支持跨年级联排；冲突需人工调整约束后重排，暂无「一键改排」。
- 安装包未做 Authenticode，macOS 为 ad-hoc 签名，未做公证（首次打开可能需右键「打开」）。
- 检查更新：SECTL 镜像由第三方同步，新版本发布后 `versions` 表先登记、`packages` 表后补，中间有窗口期——此时会如实报「已在镜像上登记，但安装包还没同步完成」，而不是说「已是最新」。
- 检查更新：镜像上尚未出现的新版本查不到；镜像不可用时需手动切回 GitHub（不会自动回退，因为用户明确选了镜像）。

## 候选改进

1. **PDF 转图片打包 zip**：现在输出文件夹；若要一键分享，可在完成后自动打 zip。
2. **文件选择器 E2E**：用 UI 自动化覆盖原生对话框，补齐 `--selftest` 未覆盖的部分。
3. **Word→PDF 图片**：解析 `w:drawing` 的 `a:blip` 关系并嵌入图片（PDF→Word 版面模式已能反向嵌入，可复用思路）。
4. **PDF 转 Word 版面模式压缩**：当前每页 PNG @150 DPI，DOCX 偏大，可改 JPEG 或 WebP。
5. **linux-arm 支持**：需替换 QuestPDF 或对这两个工具做「不可用」降级；在此之前矩阵保持 7 RID。
6. **偏好设置 / 处理记录**：记住上次输出目录、水印文字、DPI。
7. **Windows 代码签名 / macOS 公证**：需要证书与 Apple 开发者账号。
8. **归位拖拽排座 / 撤销**：把学生从名单拖到座位，或座位之间互换；加撤销/重做。（座位间拖拽互换已支持；撤销/重做仍缺）
9. **归位多班级**：保存多个班级的名单与座位配置，一键切换；可复用现有 config xlsx。
10. **归位直接打印**：接入系统原生打印对话框，而不只是打开 PDF。
11. **归位区域限制的 UI**（1.28.0 计划）：`SeatZone` / `SeatRect` 与配置读写已在 1.25.0 落地，但画格子的编辑器留到 1.28.0。
12. **归位撤销 / 重做**：目前所有操作都不可撤销，误删一排只能重来。
13. **归位交互增强**（1.29.0 计划）：导师制、拼音找人、全屏投影 / PPTX、导入别名增强。
14. **时序批量导出**：一次导出全校或全年级的课程表 PNG / PDF，按班级命名。
15. **时序作息模板**：把时间行做成可编辑，适配不同学校的作息。
16. **织序课服 / 晚修自动编排**：把课后服务与晚修纳入扩展时段并参与排课。
17. **织序跨年级编排**：同一份工作簿含多个年级时的联排与教师跨年级占用。
18. **织序 B 层学生名单**：导入分层名单，导出 A/B 层学生个人课表与走班通知。

## 版本节奏建议

- 新增小工具或新平台 → Minor（当前基线 1.35.0，下一档 1.36.0）。
- 只修 UI / 文案 / 兼容性 → Patch（1.31.x）。
- 工具 ID 或输出结构变化 → Major（2.0.0）。
- 版本号只改 `Directory.Build.props`，不要改工作流。
