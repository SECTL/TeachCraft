# 知微 × 集控：各职位功能一览

> 写给学校里的每一位老师和管理者看：不需要懂任何技术，只说清两件事——**你能用它做什么**、**什么时候它替你干活**。
> 学生姓名与成绩全程留在本机或校内，不经过任何云端——这一点全校适用，后文不再重复。

---

## 一句话总览

知微 + 集控 = 一间**「插电就正确」**的教室。

谁走进教室，大屏上就是当下该显示的课表、座位或考场安排；谁被临时派去监考、代课、看班，屏替他把一切备好。**会操作的人只有几个，受益的是全校**——大多数老师什么都不用装、什么都不用学。

---

## 一、班主任

> 使用频率：开学时花 10 分钟做一次设置；之后每学期用到几次，大部分时间什么都不用做。

**第一次使用（开学，约 10 分钟）**

- 按指引把本班名单导入教室讲台机（U 盘或校内共享盘，一次即可）。
- 在软件里输入学校给的接入码，让本班大屏「入网」。
- 电教老师确认一次保护卡白名单（他们 5 分钟，你 0 分钟）。

之后这台教室的大屏就像学校的铃声一样——**自己知道自己该显示什么**。

**日常能用到的**

| 场景 | 以前怎么做 | 现在怎么做 |
|---|---|---|
| **每学期 4–6 次换座位** | 打印 A4 举着念，或 U 盘拷到讲台机 | 在自己笔记本上排好，点一下「下发到教室」，第二天早读大屏已显示新座位（学生视角，学生抬头找自己） |
| **临时换教室 / 公开课** | 带着名单文件到处拷 | 借用任何一间已接入的教室，屏上自动显示你要的东西 |
| **外出培训 / 请假那天** | 微信发座位表照片 + 电话指挥代课 | 在办公室（甚至家里）远程把座位表、课表推到教室大屏，代课老师进门就位 |
| **家长会** | U 盘拷 PPTX | 本机一键导出 16:9 座位表页，插上就用（这条是本机功能，不依赖集控） |
| **学生矛盾问「谁坐谁旁边」** | 翻记录 | 归位软件里直接查同桌与邻座关系（纯本机，不上网） |

**班主任不用学的**：换座、排座、导出全部在归位软件里完成，操作和现在完全一样；集控只是让「导出」多了一个「直接送到教室大屏」的去处。

## 二、科任老师（不坐班、教多个班）

> 使用频率：监考每学期几次、看班值日每周轮到；每次都是**零操作**——你走进教室，东西已经在屏上。

| 场景 | 说明 |
|---|---|
| **监考进场** | 考场座位表、座号已经在考场大屏上（考务老师考前一晚统一布置）。你不用带任何东西，不用问「我这个考场的座位表呢」 |
| **早读 / 晚自习看班** | 你不认识这个班、手里没有名单——抬头看大屏就是当前座位表，点名按屏来 |
| **走班课时段** | 教室大屏自己写着「本节课：英语 · 高一3班走班」，走错教室的学生少了，你也不用每节课开头解释一遍 |
| **课间顺手关投影** | 上一位老师的屏没关？在手机网页上点一下就关了（年轻老师常用；不用跑上讲台碰别人的机器） |
| **调课通知** | 调课走系统后，教室大屏同步更新——学生不会再拿着旧课表问你 |

**科任老师不用学的**：以上全部是「走进去就有」或「手机点一下」，没有任何需要培训的操作。

## 三、考务老师 / 考务负责人

> 使用频率：每学期期中期末各一次大考；你的工作从「考前一晚跑 12 间教室」变成「考前一晚在办公室点几下」。

**考前一晚（约 21:00–22:00，原来是跑楼时间）**

1. 在归位里把 12 个考场排好（自动列数、蛇形座号——这个功能本来就有）。
2. 在集控网页上把 12 份考场座位图**按考场分组一次下发**——每份只送到对应那间教室的大屏。
3. 顺手核对：网页上能看到每间考场「设备在线、已显示 44 座」。

**考试当天早上（7:20，原来是赌博时间）**

- 在考务室看一眼网页：12 间考场是否全部就位、每间显示多少人。
- 发现某间没就位？远程重推一次，不用跑楼。
- 断网也不怕：教室机存着考前最后一份内容，照常显示。

**考试期间**

- 考场大屏锁定，学生动不了。
- 监考老师进场即用，全程零操作。

**考后**

- 一键批量还原 12 间教室的日常显示（和「开考场」成对设计，开了就能关）。
- 每次下发的考场安排都有记录（谁、几点、推的哪一版）——学期末有争议时拿得出证据。

**注意**：桌贴（贴在课桌上的那种）**不走系统**——它含学生姓名，仍由文印室打印、人工张贴。系统里的大屏版只有座号，没有姓名。

## 四、教务主任

> 使用频率：调课每周 3–5 次、开学和考试周是主战场。你的核心收获不是省时间，是**「通知到位」从口头变成可查记录**。

| 场景 | 说明 |
|---|---|
| **排课签发** | 织序排完全年级课表后，60 个班一次导入，每间教室的屏自动显示本班课表。不会再出现「班里的表和教务处的不一致」 |
| **周五调课、周一生效** | 在织序里调整、标注生效日期，受影响的班自动更新，其余班不受打扰。谁改的、几点改的、改了哪几个班——全部有记录 |
| **全校通知** | 考试周、演习、临时集合：一条通知推到全校大屏，可设过期时间（到点自动消失，不用挨班撤）。广播听不清、班主任群有延迟的问题解决了 |
| **开学点名** | 网页上看全校 60 间教室：哪些班装了、哪些在线、版本是否统一。没装的班一目了然，制度才推得动 |
| **考场接管** | 考试周大屏由考务统一接管（制度层面），班主任不用也不能动——出错面最小 |

**教务主任要守的一条纪律**：调课必须在织序里录入，不能只在群里说——大屏说的是系统里那一份，「群里发了但没进系统」，大屏就会说错话。

## 五、电教 / 信息中心

> 使用频率：装机季集中忙一次，之后每周巡检、每天看报修分流。你是这套系统在学校里的「唯一操作员」。

| 场景 | 说明 |
|---|---|
| **批量装机** | 教室助手（管家程序）静默安装到 60 间教室 + 教师办公机，各教学软件由助手统一接入集控；保护卡白名单做成安装步骤，装完自检（重启一次确认凭据还在，绿勾才收工） |
| **一机一行** | 设备列表按机器显示：一间教室一行，展开是这台机器装的各软件（各自版本、各自占的班、各自在线态）——不再一间教室三行 |
| **版本巡检** | 网页一屏看全部设备：每个软件的版本号、机器在线状态，不再逐台远程桌面查 |
| **报修分流** | 老师报「大屏没显示」：先看网页——是没装、掉线、被占用还是没下发，一眼定位，不用先跑楼 |
| **换新机** | 删掉旧设备、新机重新配对；删的是整台机器，上面所有软件一次全部真正下线 |
| **故障取证** | 学期末的审计记录可以按时间导出——出了事能自证，这个对你比什么都重要 |
| **向校长的反对意见** | 「先在一个年级试点，再铺全校」；「云平台没有服务商 SLA，考试当天的实时操作要前置到考前 30 分钟验收」 |

## 六、校长 / 德育处（看全局的）

> 使用频率：几乎不操作，但要看得懂三件事。

1. **大屏从「显示工具」变成「校园广播位」**：紧急通知、演习指令能直达每间教室，且有送达记录。
2. **考试周可控**：考场布置从「12 个老师各管各的」变成「一个人在网页上分配、监考零操作进场」，教学事故面最小。
3. **红线在系统层锁死**：学生成绩、名单、家庭信息在设计上就进不了云端——不是靠自觉，是靠字段里根本没这些。桌上贴的、屏上显示的姓名由学校统一开关控制。

## 七、总表：谁在什么时候用它

| 身份 | 高频场景 | 每学期几次 | 需要学习吗 |
|---|---|---|---|
| 班主任 | 换座下发、代课日远程布置 | 4–6 次换座 + 若干次外出 | 开学 10 分钟向导 |
| 科任（流动） | 监考进场、看班点名 | 监考 2–4 次、值日每周 | **零** |
| 年轻教师 | 课间关投影、巡屏 | 每天（低频） | 零（网页） |
| 老教师 | 什么都不用做，屏自己工作 | 每天（被动） | **零** |
| 考务 | 考场批量下发、7:20 核验、一键还原 | 2 次大考 | 一次流程讲解 |
| 教务 | 调课下发、通知广播、点名 | 调课每周 3–5 起 | 织序本来就会用 |
| 电教 | 装机、巡检、报修分流、审计 | 装机季 + 日常 | 装机 SOP |
| 监考/代课/值日（全员轮值） | 进场即用 | 人人轮到 | **零** |

**一句给所有人的话**：这套系统的设计目标，是让 52 岁、只用微信和 PPT 的老教师**察觉不到它存在**——大屏像铃声一样自己就对了。任何需要「先培训再使用」的功能，都不会出现在你的日常里。

## 附：它做不到的事（如实说）

- **运动会教室屏**：运动会当天教室是空的，检录处一张纸更实用——赛前提醒用文字通知即可。
- **家长会大屏**：你本来就站在讲台机前，本机导出的座位表页完全够用，系统不添乱也不添彩。
- **成绩条上云**：**永远不会做**。成绩条在你笔记本上生成、打印、裁剪，全程不出网线——这是全系统最重要的负功能。
- **断网时**：教室屏显示断网前最后的内容（照常可用），只是不能远程改——而考试当天本来也不该改。
- **功能教室**：实验室、机房、图书馆目前挂在结构树之外，这类教室暂不覆盖。
- **后勤值班 / 宿管 / 校医**：与教室大屏无关，不在覆盖范围。
