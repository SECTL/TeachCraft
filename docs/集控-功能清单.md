## 2. 设备接入与生命周期

| 能力 | 说明 |
|---|---|
| **双因子接入**（免登录） | `POST /control/api/enroll`：地点ID + 配对码 → `deviceId` + `secret`（64 字符 base64url，**只回一次**，库存 sha256）。失败码阶梯固定 10 级，非成员口径一律 404 不 403 |
| **账号接入** | `POST /device/enroll`（v4.4）：SECTL OAuth access token 或 Appwrite JWT，operator 起；同机已接入时 admin 可**接管**（复用 deviceId、轮换 secret） |
| **配对码** | 8 位、31 字符表（剔 0O1IL）、默认 24h（1–168 可调）、最多用 5 次、每地点同时 20 张、可预绑 platform 与 classId；明文只显一次 |
| **机器指纹** | `sha256(guid|host).slice(0,16)`——只用于跨地点冲突提示，非鉴权 |
| **设备自助**（凭 secret） | `device/tree` 读结构树、`device/assign` 自助选班（空 = 解除；换班须先解除再绑定两步）、`device/unenroll` 自助退订（吊销+删记录，不可撤销） |
| **设备管理** | 列表 / 改名 / 改班 / 轮换密钥 / 删除；名称同地点查重，重名自动加 ` (2)` |
| **限速** | enroll：同 IP 10 次失败/分、同地点 50 次/时→冷却 15 分；账号接入：同账号 20 次/10 分、同 IP 60 次/时 |

**hello 上报**（首帧 10s 内，超时关 4002）：`protocol / platform / device_id / secret / device_name / version / capabilities[] / applied_state_revision / settings{revision,schema} / options{revision,commands}`。声明了不在平台能力表内的能力**静默丢弃**（不报错）。

**心跳**：25s 一跳，75s 无心跳判离线；断开立即清占用，无宽限期。

## 3. 占用与状态语义

| 概念 | 规则 |
|---|---|
| **占班** `class.select` | 抢 `(class_id, platform)` 键的**全局独占**；占班=上课=允许抽取；同帧下发 `desired_state{draw_locked:false}` 并落库 |
| **顶替** `superseded` | 后来者顶掉先到者，被顶方收 `evicted{reason:'superseded'}` 回未选班；对顶替限流 3 秒防抖（`busy` + `retry_after_ms`），首占不限 |
| **吊销** `revoked` | 凭证吊销立即踢线（`evicted{reason:'revoked'}` + 关闭码 4003），清凭证停重连 |
| **重连顶替** `replaced` | 同设备在别处重连，旧连接退 4004 |
| **释放** `class.release` | 下课=禁止抽取，落库；可只带 platform 反查占用 |

## 4. 指令通道（已核实）

**机制**：网页/管理端 → `hub.sendCommand({classId, platform, cmd, args})` → 查占用表唯一持有者 → 单台下发。**两帧回执**（`cmd.ack` → `cmd.result`，`command_id` 两帧都回填）；设备侧校验顺序固定：过期 → 本机开关 → 能力未声明 → 幂等缓存（LRU 512 落盘）→ 执行。服务端超时 **5 秒**；有效期默认 120s（可调 1s–1h）；**不补投**——离线即 409 `offline`，超时/过期 504。慢操作回 `DeferredReply` 稍后补报。`needsConfirm` 只是前端二次确认提示，服务端不读。

| SecRandom（12 条） | `broadcast` | text≤200、seconds | operator | 否 |
| | `lockScreen` | message≤60、unlockAfterSeconds | operator | **是** |
| | `restartClient` | delaySeconds（有效期仅 30s） | admin | **是** |
| | `switchPage` | page∈rollCall/quickDraw/lottery | operator | 否 |
| | `draw.trigger` | target/list_name/count/gender/group | operator | 否 |

## 6. 客户端自描述

| 通道 | 说明 | 限额 |
|---|---|---|
| `settings.schema` | hello 上报设置项（bool/enum/int/string/duration 五种控件 + 分组/范围/默认值），控制台按 schema 通用渲染；写回走 `settings.write`，服务端按 schema 逐键校验 | ≤40 项、≤8 分组、≤16 KiB |
| `options.report` | 上报命令参数候选值（只对 string/enum），控制台渲染下拉；多设备取并集 + 冲突标记 | ≤16 命令、8 参数、64 值、8 KiB |

客户端**能**自声明设置与参数候选；**不能**自声明命令或权限（`writable` 由服务端角色表算，schema 里的 risk/role 字段被忽略）。仓库内两个参考客户端尚未上报这两样——是预留能力。

## 9. 本机 IPC（命名管道）

`\\.\pipe\sectl-<platform>`，NDJSON，消息形状与 WS 同构。同机任意进程免网络读：`ping`、`roster.read`（宿主 RosterProvider 提供）、`class.changed` 广播。首实例持 `FirstPipeInstance`，多开不影响业务。无 ACL 无鉴权——只传本机可公开的数据。Windows-only（其他平台 `Available=false`）。

## 10. 客户端 SDK（.NET）

`SectlControlClient.cs`（namespace `Sectl.Control`，零 NuGet，TFM 下限 net6.0）：

- 方法：`Start / StopAsync / EnrollAsync / ClearCredential / SelectClassAsync / ReleaseClassAsync / GetTreeAsync / ReportAsync / RequestAsync / DropConnectionAsync / WaitStateAsync`
- 回调（全部后台线程）：`OnState / OnCommand / OnEvicted / OnTree / OnDesiredState / OnLog`
- 状态机 8 态：Unconfigured → Configured → Connecting → Connected → Selected → Superseded / Revoked / Stopped
- 退避重连 1→2→4…60s ±20%；`DeferredReply` 支持慢操作；幂等缓存 LRU 512 落盘
- 适配层 `ControlCenterService`：`StartAsync` 绝不抛、`RegisterHandler`（未注册如实回 unsupported）、`EnrollCodeConsumed` 事件、`Snapshot` 给 UI

已知坑（clients/README §4）：同步命名管道「阻塞读+并发写」必死锁（须 `Asynchronous`）；收尾不得把 `REVOKED` 覆盖成 `STOPPED`。

## 14. 明确没有的能力（边界）

1. **没有文件分发**——无 multipart、无上传端点、`readBody` 128 KiB；`pushImage` 只是指挥客户端取 URL 且已删。
2. **没有调度器/定时任务**——命令是「现在做」，无 cron。
3. **没有按设备下发指令**——`sendCommand` 只认 `(classId, platform)` 占用表；不占班的设备收不到任何指令（协议核实结论）。
4. **没有 class 级期望状态**——现有 `desired_state` 按设备、只四字段、在内存。
5. **没有批量下发端点**——命令单班，60 班只能循环。
6. **设备读不到 seats**——REST 要用户令牌；device secret 只有 tree/assign/unenroll。
7. **版本号不透出**——hello 里有 `version`，`shapeDevice` 不回。
8. **平台不能动态注册**——加平台必须改服务端代码四处。
9. **功能教室无节点**——结构树只有地点→年级→班级，实验室/机房/图书馆挂不进去。
